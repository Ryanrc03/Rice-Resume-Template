# Rice-Resume-Template

This repository contains a LaTeX resume template tailored for Rice University. The template is designed to be clean, professional, and easy to customize.

## Features
- Modern and elegant design
- Customizable sections
- Rice University theme colors

## Usage
1. Clone this repository:
   ```bash
   git clone https://github.com/Ryanrc03/Rice-Resume-Template.git
   ```
2. Open `main.tex` in your LaTeX editor.
3. Customize the content as needed.
4. Compile the LaTeX file to generate your resume.
